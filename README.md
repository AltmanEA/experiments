# experiments

Экспериментальный репозиторий: прогоны и метрики для статьи о квантовании рассуждений
(paper-reasoning-quantization, P-001 / P-002 / P-003).

Выделен из репозитория `council` 2026-11-12 как отдельный локальный репозиторий.

## Содержимое

- `paper-reasoning-quantization/PLAN.md` — план экспериментов.
- `paper-reasoning-quantization/NOTES.md` — журнал решений и наблюдений.
- `paper-reasoning-quantization/STATUS.md` — текущее состояние прогонов и судейства.
- `corpus/` — фикстуры S1–S7 и пары терминов глоссария.
- `runs/` — сырые выводы моделей по условиям C1–C6, K0.
- `judge/` — результаты LLM-судейства (absolute / pairwise).
- `metrics/` — скрипты агрегации, дефектов, MQM, таблиц статьи.
- `results/` — сводные таблицы и CSV.

## Зависимость от council

Скрипты прогонов (`run_*.sh`, `cloud_*.sh`, `queue.sh`) и часть `metrics/*.py` обращаются
к файлам родительского проекта по относительным путям:

- `../../tools/local_translate.py` — переводчик;
- `../../docs/en/glossary/index.md` — глоссарий.

Эти пути рассчитаны на размещение каталога `paper-reasoning-quantization/` внутри
`council/experiments/`. При запуске из этого репозитория передавайте пути явно
(например, `GLOSS=/path/to/council/docs/en/glossary/index.md`) или запускайте скрипты
из клона `council`. Исторические прогоны уже выполнены и не требуют повторного запуска.
