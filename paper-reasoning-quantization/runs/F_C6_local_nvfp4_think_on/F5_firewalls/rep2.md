# Брандмауэры

## IPFW

### Включение IPFW

Чтобы включить IPFW при загрузке системы, добавьте `firewall_enable="YES"` в `/etc/rc.conf`:

```shell
# sysrc firewall_enable="YES"
```

Чтобы использовать один из стандартных типов межсетевого экрана, предоставляемых FreeBSD, добавьте еще одну строку, указывающую тип:

```shell
# sysrc firewall_type="open"
```

Доступные типы:

* `open`: пропускает весь трафик.
* `client`: защищает только эту машину.
* `simple`: защищает всю сеть.
* `closed`: полностью отключает IP-трафик, кроме интерфейса loopback.
* `workstation`: защищает только эту машину с использованием правил с отслеживанием состояния.
* `UNKNOWN`: отключает загрузку правил межсетевого экрана.
* `filename`: полный путь к файлу, содержащему набор правил межсетевого экрана.

Если `firewall_type` установлено в значение `client` или `simple`, измените правила по умолчанию, найденные в `/etc/rc.firewall`, чтобы они соответствовали конфигурации системы.

Чтобы включить ведение журнала через `syslogd(8)`, добавьте эту строку:

```shell
# sysrc firewall_logging="YES"
```

Чтобы ограничить количество раз, когда правило логируется при каждой попытке подключения, укажите число, добавив следующую строку в `/etc/sysctl.conf`:

```shell
# echo "net.inet.ip.fw.verbose_limit=5" >> /etc/sysctl.conf
```

Затем используйте tcpdump, чтобы увидеть, что записывается в журнал:

```shell
# tcpdump -t -n -i ipfw0
```

После сохранения необходимых изменений запустите межсетевой экран. Чтобы включить ограничения ведения журнала сейчас, также установите значение `sysctl`, указанное выше:

```shell
# service ipfw start
# sysctl net.inet.ip.fw.verbose_limit=5
```
