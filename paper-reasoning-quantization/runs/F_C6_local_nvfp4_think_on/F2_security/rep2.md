# Безопасность

## Параметры безопасности SSH-сервера

Хотя sshd является наиболее широко используемым средством удалённого администрирования для FreeBSD, brute-force и drive-by-атаки характерны для любой системы, открытой для публичных сетей.

Для предотвращения успешного осуществления этих атак доступны несколько дополнительных параметров, которые будут описаны в данном разделе. Все настройки будут производиться в /etc/ssh/sshd_config

> **СОВЕТ**
>
> Не путайте /etc/ssh/sshd_config с /etc/ssh/ssh_config (обратите внимание на лишнюю `d` в первом имени файла). Первый файл настраивает сервер, а второй — клиент. Список доступных настроек клетка см. в `ssh_config(5)`.

По умолчанию аутентификация может выполняться с помощью как открытого ключа, так и пароля.
Чтобы разрешить *только* аутентификацию по открытому ключу, *что настоятельно рекомендуется*, измените переменную:

```
PasswordAuthentication no
```

Хорошей идеей будет ограничить, какие пользователи могут входить на SSH-сервер и откуда, используя ключевое слово `AllowUsers` в конфигурационном файле сервера OpenSSH. Например, чтобы разрешить вход только `user` с `192.168.1.32`, добавьте эту строку в /etc/ssh/sshd_config:

```
AllowUsers user@192.168.1.32
```

Несколько пользователей должны быть указаны на одной строке, следующим образом:

```
AllowUsers root@192.168.1.32 user
```

После внесения всех изменений и перед перезапуском службы рекомендуется проверить корректность внесенной конфигурации, выполнив следующую команду:

```shell
# sshd -t
```

После внесения изменений и проверки корректности файла конфигурации, сообщите sshd о необходимости перезагрузить файл конфигурации, выполнив:

```shell
# service sshd reload
```

## OpenSSL

OpenSSL представляет собой набор криптографических инструментов, реализующий сетевые протоколы Secure Sockets Layer (SSL) и Transport Layer Security (TLS), а также множество криптографических функций.

Программа openssl — это инструмент командной строки для использования различных криптографических функций криптографической библиотеки OpenSSL из командной оболочки. Её можно использовать для:

* Создание и управление закрытыми ключами, открытыми ключами и параметрами
* Криптографические операции с открытым ключом
* Создание сертификатов X.509, CSRs и CRLs
* Вычисление дайджестов сообщений
* Шифрование и расшифрование с помощью шифров
* Тестирование клиентов и серверов SSL/TLS
* Обработка подписанных или зашифрованных писем S/MIME
* Запросы временных меток, их генерация и проверка
* Бенчмаркинг криптографических функций
