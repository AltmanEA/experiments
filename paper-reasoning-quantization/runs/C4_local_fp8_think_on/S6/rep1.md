## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы Ролей, объединяет выводы по `subject_id`, оценивает Консенсус через Layer 0 и маршрутизирует Эскалацию. Он не выполняет интерпретацию свободного текста, не обладает правом принятия решений и не содержит вызовов LLM. Решения по Фаза и Консенсус являются детерминированными функциями проверенных выходов Ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов из валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берется из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все примененные замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | обзоры аналитических-задач |
| top_p | 0.9 | обзоры аналитических-задач |
| frequency_penalty | 0.0 | нейтральный (установлен явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в файле `defaults/policy.yaml`. Для его расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (точка зрения, обязанности, напоминание о структуре вывода)
- За пределами определения роли и контекста сценария не добавляются несанкционированные инструкции

### Session manifest traceability

Каждая запись сессии включает раздел "Роль_agent_config", в котором перечислены точные параметры, использованные для каждой активной роли, с возможностью прослеживания до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентом/вставкой контекста — поведенческая подмена запрещена.
