## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения по Фазе и Консенсусу являются детерминированными функциями проверенных выходов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берется из задокументированного безопасного замечания, отображаемого в манифесте сессии. Магических значений по умолчанию не предусмотрено. Все примененные замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | аналитическая-задача обзоры |
| top_p | 0.9 | аналитическая-задача обзоры |
| frequency_penalty | 0.0 | нейтральная (установлена явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в `defaults/policy.yaml`. Для его расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит необходимые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Отсутствуют несанкционированные инструкции, добавленные за пределами определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел "Роль_agent_config", в котором перечислены точные параметры, использованные для каждой активной роли, которые можно отследить до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентом/вставкой контекста — поведенческая подмена запрещена.
