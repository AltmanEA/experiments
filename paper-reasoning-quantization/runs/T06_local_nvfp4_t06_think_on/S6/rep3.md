## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения о фазе и консенсусе являются детерминированными функциями проверенных выходов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, ИЛИ берётся из задокументированного безопасного замечания, доступного в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию указываются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область действия |
|-----------|---------|-------|
| temperature | 0.1 | аналитическая-задача: обзоры |
| top_p | 0.9 | аналитическая-задача: обзоры |
| frequency_penalty | 0.0 | нейтральный (задан явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в `defaults/policy.yaml`. Для расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Отсутствуют несанкционированные инструкции, добавленные за пределами определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, перечисляющий точные параметры, используемые для каждой активной роли, которые можно отследить до конфигурации сценария → резолюции фабрики → фактического инстанцирования агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предыдущей фазы), но НЕ модифицирует базовый шаблон запроса роли. Настройка запроса ограничивается только акцентом/вставкой контекста — поведенческая подмена запрещена.
