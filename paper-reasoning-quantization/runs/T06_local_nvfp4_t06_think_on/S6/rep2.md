## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями проверенных выводов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берётся из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию указываются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область действия |
|-----------|---------|-------|
| temperature | 0.1 | ревью аналитических-задач |
| top_p | 0.9 | ревью аналитических-задач |
| frequency_penalty | 0.0 | нейтральный (задан явно, никогда не выводится) |

Стандартный белый список централизованно управляется в `defaults/policy.yaml`. Для его расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли совпадает с известной ролью из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Запрещено добавлять несанкционированные инструкции за пределы определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, в котором перечислены точные параметры, используемые для каждой активной роли, с возможностью проследить их до конфигурации сценария → фабричной резолюции → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, имя сценария, результаты предфазы), но НЕ модифицирует базовый шаблон запроса роли. Настройка запроса ограничена только введением акцента/контекста — поведенческая подмена запрещена.
