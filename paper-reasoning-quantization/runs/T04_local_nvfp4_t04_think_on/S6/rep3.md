## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает правом принятия решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями проверенных выходов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевого агента из валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берется из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все примененные замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | отзывы по аналитической-задаче |
| top_p | 0.9 | отзывы по аналитической-задаче |
| frequency_penalty | 0.0 | нейтральный (задан явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в `defaults/policy.yaml`. Для его расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- За пределами определения роли и контекста сценария не добавляются несанкционированные инструкции

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, в котором перечислены точные параметры, использованные для каждой активной роли, которые можно проследить до конфигурации сценария → резолюции фабрики → фактического инстанцирования агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена исключительно введением акцента/контекста — поведенческая подмена запрещена.
