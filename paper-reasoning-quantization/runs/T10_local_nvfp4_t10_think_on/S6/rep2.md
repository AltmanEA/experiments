## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию произвольного текста, не наделён полномочиями по принятию решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями валидированных выходов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов из проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, отображаемого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии под ключом `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | обзоры аналитических задач |
| top_p | 0.9 | обзоры аналитических задач |
| frequency_penalty | 0.0 | нейтрально (явно задано, никогда не выводится) |

Белый список по умолчанию управляется централизованно в `defaults/policy.yaml`. Для расширения необходимо создать PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли совпадает с известной ролью из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Отсутствуют несанкционированные инструкции, добавленные после определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии содержит раздел `"role_agent_config"`, в котором указаны точные параметры, использованные для каждой активной роли, и которые можно отследить до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена исключительно вставкой акцентов/контекста — замена поведения запрещена.
