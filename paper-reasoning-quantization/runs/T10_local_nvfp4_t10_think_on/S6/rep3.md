## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает Консенсус через Layer 0 и маршрутизирует Эскалацию. Он не выполняет интерпретацию свободного текста, не принимает решений и не содержит вызовов LLM. Решения по Фазе и Консенсусу являются детерминированными функциями от верифицированных выходов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо задан вызывающей стороной, либо взят из задокументированного безопасного замечания, доступного в манифесте сессии. Никаких магических значений по умолчанию. Все примененные замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | обзоры аналитической-Задачи |
| top_p | 0.9 | обзоры аналитической-Задачи |
| frequency_penalty | 0.0 | нейтрально (задаётся явно, никогда не вычисляется) |

Стандартный белый список управляется централизованно в `defaults/policy.yaml`. Расширение требует PR с обоснованием. Рассматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор Роль соответствует известной Ролью из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Нет несанкционированных инструкций, добавленных после определения Роль и контекста Сценарий

### Session manifest traceability

Каждая запись сессии включает секцию `"role_agent_config"`, содержащую точные параметры, использованные для каждой активной роли, которые можно проследить до конфигурации сценария → резолюции фабрики → фактического создания агента.

### No prompt modification rule

Фабрика подставляет специфичный для сценария контекст (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только подстановкой акцента или контекста — замещение поведения запрещено.
