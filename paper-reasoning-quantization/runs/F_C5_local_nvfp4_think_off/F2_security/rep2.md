# Безопасность

## Параметры безопасности SSH-сервера

Хотя sshd является наиболее широко используемым средством **удалённое администрирование** для FreeBSD, атаки методом перебора и «на лету» распространены для любой системы, подключенной к публичным сетям.

Для предотвращения успешного осуществления этих атак доступны несколько дополнительных параметров, которые будут описаны в данном разделе. Все настройки выполняются в файле /etc/ssh/sshd_config

> **ПОДСКАЗКА**
>
> Не путайте /etc/ssh/sshd_config с /etc/ssh/ssh_config (обратите внимание на дополнительную букву `d` в первом имени файла). Первый файл настраивает сервер, а второй — клиент. Список доступных настроек клетка см. в `ssh_config(5)`.

По умолчанию аутентификация может выполняться как с использованием открытого ключа, так и с помощью пароля.
Чтобы разрешить *только* аутентификацию по открытому ключу, *что настоятельно рекомендуется*, измените переменную:

```
PasswordAuthentication no
```

Хорошей идеей будет ограничить круг пользователей, которые могут подключаться к серверу SSH, и адреса, с которых это разрешено, используя параметр `AllowUsers` в конфигурационном файле сервера OpenSSH. Например, чтобы разрешить вход только пользователю `user` с адреса `192.168.1.32`, добавьте следующую строку в /etc/ssh/sshd_config:

```
AllowUsers user@192.168.1.32
```

Несколько пользователей должны быть перечислены на одной строке, например так:

```
AllowUsers root@192.168.1.32 user
```

После внесения всех изменений, перед перезапуском службы рекомендуется проверить правильность выполненной конфигурации, выполнив следующую команду:

```shell
# sshd -t
```

После внесения изменений и проверки корректности Файл конфигурации, сообщите sshd перезагрузить файл конфигурации, выполнив:

```shell
# service sshd reload
```

## OpenSSL

OpenSSL — это набор криптографических инструментов, реализующий сетевые протоколы Secure Sockets Layer (SSL) и Transport Layer Security (TLS), а также множество криптографических процедур.

Программа openssl — это **инструмент командной строки** для использования различных криптографических функций криптографической библиотеки OpenSSL из оболочки. Её можно использовать для:

* Создание и управление закрытыми ключами, открытыми ключами и параметрами
* Криптографические операции с открытым ключом
* Создание сертификатов X.509, запросов на подпись сертификатов (CSR) и списков отзыва сертификатов (CRL)
* Вычисление дайджестов сообщений
* Шифрование и расшифрование с помощью шифров
* Тестирование клиентов и серверов SSL/TLS
* Обработка электронной почты, подписанной или зашифрованной с помощью S/MIME
* Запросы временных меток, их генерация и проверка
* Бенчмаркинг криптографических функций
