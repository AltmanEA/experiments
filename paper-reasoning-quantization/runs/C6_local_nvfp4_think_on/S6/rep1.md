## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, группирует выводы по `subject_id`, оценивает Консенсус через Layer 0 и маршрутизирует Эскалацию. Он не выполняет интерпретацию произвольного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения относительно Фазы и Консенсуса являются детерминированными функциями проверенных результатов ролей; ни одна модель не участвует в потоке управления или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берётся из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | аналитическая-задача обзоры |
| top_p | 0.9 | аналитическая-задача обзоры |
| frequency_penalty | 0.0 | нейтральная (задача явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в `defaults/policy.yaml`. Для его расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Отсутствуют несанкционированные инструкции, добавленные за пределами определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел "Роль_agent_config", перечисляющий точные параметры, использованные для каждой активной роли, которые можно отследить обратно до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентированием/введением контекста — поведенческая подмена запрещена.
