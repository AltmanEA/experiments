# Диски

## Квоты на диске

Квоты на диске можно использовать для ограничения объема дискового пространства или количества файлов, которые пользователь или члены группы могут выделить на уровне файловой системы. Это предотвращает потребление одним пользователем или группой пользователей всего доступного дискового пространства.

В этом разделе описывается, как настроить квоты диска для файловой системы UFS. Для настройки квот в файловой системе ZFS обратитесь к разделу «Квоты для наборов данных, пользователей и групп».

### Включение квот диска

Чтобы определить, поддерживает ли ядро FreeBSD квоты диска:

```shell
% sysctl kern.features.ufs_quota
kern.features.ufs_quota: 1
```

В данном примере `1` указывает на поддержку квот. Если значение равно `0`, добавьте следующую строку в файл конфигурации ядра и пересоберите ядро, следуя инструкциям в [Настройка ядра FreeBSD]:

```
options QUOTA
```

Далее включите квоты на диск в /etc/rc.conf:

```
quota_enable="YES"
```

Обычно при загрузке целостность квот для каждой файловой системы проверяется с помощью `quotacheck(8)`. Эта программа гарантирует, что данные в базе квот правильно отражают данные на файловой системе. Это длительный процесс, который значительно повлияет на время загрузки системы. Чтобы пропустить этот шаг, добавьте эту переменную в /etc/rc.conf:

```
check_quotas="NO"
```

Наконец, отредактируйте /etc/fstab, чтобы включить квоты на дисках для каждой файловой системы. Чтобы включить квоты для каждого пользователя на файловой системе, добавьте `userquota` в поле параметров в записи /etc/fstab для файловой системы, на которой необходимо включить квоты. Например:

```
/dev/da1s2g   /home    ufs rw,userquota 1 2
```

Для включения групповых квот используйте `groupquota` вместо этого. Чтобы включить квоты как для пользователей, так и для групп, разделяйте параметры запятой:

```
/dev/da1s2g    /home    ufs rw,userquota,groupquota 1 2
```

По умолчанию файлы квот хранятся в корневом каталоге файловой системы как quota.user и quota.group. Для получения дополнительной информации см. `fstab(5)`. Указание альтернативного расположения для файлов квот не рекомендуется.

После завершения конфигурации перезагрузите систему, и /etc/rc автоматически выполнит соответствующие команды для создания начальных файлов квот для всех квот, включенных в /etc/fstab.

В обычном режиме работы нет необходимости вручную запускать `quotacheck(8)`, `quotaon(8)` или `quotaoff(8)`. Однако следует прочитать эти страницы руководства, чтобы ознакомиться с принципом их работы.

### Настройка лимитов квот

Чтобы проверить, включены ли квоты, выполните:

```shell
# quota -v
```
