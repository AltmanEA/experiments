# Диски

## Диск Квоты

Диск-квоты могут использоваться для ограничения объема дискового пространства или количества файлов, которые пользователь или члены группы могут выделить на уровне файловой системы. Это предотвращает потребление одним пользователем или группой пользователей всего доступного дискового пространства.

В этом разделе описывается, как настроить квоты на диск для файловой системы UFS. Для настройки квот в файловой системе ZFS обратитесь к разделу «Квоты для наборов данных, пользователей и групп».

### Enabling Disk Quotas

Чтобы определить, предоставляет ли ядро FreeBSD поддержку для квот на диске:

```shell
% sysctl kern.features.ufs_quota
kern.features.ufs_quota: 1
```

В данном примере `1` указывает на поддержку квот. Если значение равно `0`, добавьте следующую строку в пользовательский файл конфигурации ядра и пересоберите ядро, следуя инструкциям в [Конфигурирование ядра FreeBSD]:

```
options QUOTA
```

Далее включите квоты дисков в /etc/rc.conf:

```
quota_enable="YES"
```

Обычно при загрузке целостность квот каждой файловой системы проверяется с помощью `quotacheck(8)`. Эта программа гарантирует, что данные в базе квот корректно отражают данные на файловой системе. Это процесс, занимающий много времени, который значительно повлияет на время загрузки системы. Чтобы пропустить этот шаг, добавьте эту переменную в /etc/rc.conf:

```
check_quotas="NO"
```

Наконец, отредактируйте /etc/fstab, чтобы включить квоты на диске на уровне каждой файловой системы. Чтобы включить квоты для каждого пользователя в файловой системе, добавьте `userquota` в поле опций в записи /etc/fstab для файловой системы, для которой нужно включить квоты. Например:

```
/dev/da1s2g   /home    ufs rw,userquota 1 2
```

Для включения групповых квот используйте `groupquota` вместо этого. Чтобы включить квоты как для пользователей, так и для групп, разделяйте параметры запятой:

```
/dev/da1s2g    /home    ufs rw,userquota,groupquota 1 2
```

По умолчанию файлы квот хранятся в корневом каталоге файловой системы как quota.user и quota.group. См. `fstab(5)` для получения дополнительной информации. Не рекомендуется указывать альтернативное расположение для файлов квот.

После завершения конфигурации перезагрузите систему, и /etc/rc автоматически выполнит необходимые команды для создания начальных файлов квот для всех квот, включенных в /etc/fstab.

В обычном режиме работы нет необходимости вручную запускать `quotacheck(8)`, `quotaon(8)` или `quotaoff(8)`. Однако следует прочитать эти страницы руководства, чтобы ознакомиться с принципом их работы.

### Настройка лимитов квот

Чтобы проверить, включены ли квоты, выполните:

```shell
# quota -v
```
