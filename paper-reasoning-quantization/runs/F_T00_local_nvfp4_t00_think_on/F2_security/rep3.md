# Безопасность

## Параметры безопасности SSH-сервера

Хотя sshd является наиболее широко используемым средством удалённого администрирования для FreeBSD, атаки методом перебора и drive-by-атаки характерны для любой системы, подключённой к публичным сетям.

Для предотвращения успешного выполнения этих атак доступны несколько дополнительных параметров, которые будут описаны в этом разделе. Все настройки будут вноситься в /etc/ssh/sshd_config

> **ПОДСКАЗКА**
>
> Не путайте /etc/ssh/sshd_config с /etc/ssh/ssh_config (обратите внимание на дополнительную букву `d` в первом имени файла). Первый файл настраивает сервер, а второй — клиент. Список доступных настроек клетка см. в `ssh_config(5)`.

По умолчанию аутентификация может выполняться как с использованием открытого ключа, так и пароля.
Чтобы разрешить *только* аутентификацию по открытому ключу, *что настоятельно рекомендуется*, измените переменную:

```
PasswordAuthentication no
```

Хорошей идеей будет ограничить, какие пользователи могут войти на SSH-сервер и откуда, используя параметр `AllowUsers` в конфигурационном файле сервера OpenSSH. Например, чтобы разрешить вход только пользователю `user` с адреса `192.168.1.32`, добавьте эту строку в /etc/ssh/sshd_config:

```
AllowUsers user@192.168.1.32
```

Несколько пользователей должны быть перечислены в одной строке, как здесь:

```
AllowUsers root@192.168.1.32 user
```

После внесения всех изменений и перед перезапуском службы рекомендуется проверить, что внесенная конфигурация корректна, выполнив следующую команду:

```shell
# sshd -t
```

После внесения изменений и проверки правильности файла конфигурации, сообщите sshd перезагрузить файл конфигурации, выполнив:

```shell
# service sshd reload
```

## OpenSSL

OpenSSL — это набор криптографических инструментов, реализующий протоколы сети Secure Sockets Layer (SSL) и Transport Layer Security (TLS), а также множество криптографических процедур.

Программа openssl — это инструмент командной строки для использования различных криптографических функций криптографической библиотеки OpenSSL из командной оболочки. Её можно использовать для:

* Создание и управление закрытыми ключами, открытыми ключами и параметрами
* Криптографические операции с открытым ключом
* Создание сертификатов X.509, CSRs и CRLs
* Вычисление дайджестов сообщений
* Шифрование и расшифрование с помощью шифров
* Тестирование клиентов и серверов SSL/TLS
* Обработка подписанных или зашифрованных писем S/MIME
* Запросы временных меток, генерация и проверка
* Тестирование производительности криптографических функций
