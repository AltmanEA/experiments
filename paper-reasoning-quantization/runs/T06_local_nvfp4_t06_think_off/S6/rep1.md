## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через слой 0 и маршрутизирует эскалацию. Он не выполняет свободный текстовый анализ, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения, связанные с фазой и консенсусом, являются детерминированными функциями проверенных выводов ролей; никакая модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевого агента на основе проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии под ключом `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | Значение по умолчанию | Область действия |
|-----------|---------|-------|
| temperature | 0.1 | analytical-task reviews |
| top_p | 0.9 | analytical-task reviews |
| frequency_penalty | 0.0 | neutral (explicitly set, never inferred) |

Список разрешённых значений по умолчанию управляется централизованно в `defaults/policy.yaml`. Для его расширения необходимо подготовить запрос на слияние (PR) с обоснованием. Пересмотр осуществляется ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли совпадает с известной ролью из `protocol-core/index.md`
- Шаблон запроса содержит необходимые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Запрещённые инструкции не добавляются за пределы определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии содержит раздел `"role_agent_config"`, в котором перечислены точные параметры, использованные для каждой активной роли, с возможностью проследить путь от конфигурации сценария → резолюции фабрики → фактической инстанции агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предшествующей фазы), но НЕ изменяет базовый шаблон подсказки роли. Настройка подсказки ограничивается только акцентированием внимания и внедрением контекста — подмена поведения запрещена.
