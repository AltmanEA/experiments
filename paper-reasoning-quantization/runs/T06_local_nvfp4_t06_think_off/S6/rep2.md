## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через слой 0 и направляет эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения, связанные с фазой и консенсусом, являются детерминированными функциями проверенных выводов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо задан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких скрытых значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область применения |
|-----------|---------|-------|
| temperature | 0.1 | analytical-task reviews |
| top_p | 0.9 | analytical-task reviews |
| frequency_penalty | 0.0 | neutral (explicitly set, never inferred) |

Список разрешённых значений по умолчанию управляется централизованно в `defaults/policy.yaml`. Для внесения изменений необходимо подготовить pull-запрос с обоснованием. Проверка осуществляется ежеквартально.

### Contract validation hook

После создания, но перед постановкой в очередь, выполните проверку:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Вне определения роли и контекста сценария не добавлены несанкционированные инструкции

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, содержащий точные параметры, используемые для каждой активной роли, которые можно отследить от конфигурации сценария → резолюции фабрики → фактической инстанции агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предыдущей фазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничивается только усилением/внедрением контекста — замена поведения запрещена.
