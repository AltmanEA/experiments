# Диски

## Диск квоты

Дисковые квоты могут использоваться для ограничения объема дискового пространства или количества файлов, которые пользователь или члены группы могут выделить на основе файловой системы. Это предотвращает потребление всего доступного дискового пространства одним пользователем или группой пользователей.

В этом разделе описывается, как настроить квоты дисков для файловой системы UFS. Для настройки квот в файловой системе ZFS обратитесь к разделу «Квоты для наборов данных, пользователей и групп».

### Включение квот дискового пространства

Чтобы определить, поддерживает ли ядро FreeBSD квоты для дисков:

```shell
% sysctl kern.features.ufs_quota
kern.features.ufs_quota: 1
```

В данном примере значение `1` указывает на поддержку квот. Если же значение равно `0`, добавьте следующую строку в файл конфигурации пользовательского ядра и пересоберите ядро, следуя инструкциям из [Configuring the FreeBSD Ядро]:

```
options QUOTA
```

Далее включите квоты дисков в /etc/rc.conf:

```
quota_enable="YES"
```

Обычно при загрузке целостность квот каждой файловой системы проверяется с помощью `quotacheck(8)`. Эта программа гарантирует, что данные в базе квот корректно отражают данные на файловой системе. Это ресурсоемкий процесс, который значительно увеличивает время загрузки системы. Чтобы пропустить этот шаг, добавьте следующую переменную в /etc/rc.conf:

```
check_quotas="NO"
```

Наконец, отредактируйте /etc/fstab, чтобы включить квоты дискового пространства для каждой файловой системы. Чтобы включить квоты для каждого пользователя в файловой системе, добавьте `userquota` в поле параметров в записи /etc/fstab для файловой системы, на которую нужно включить квоты. Например:

```
/dev/da1s2g   /home    ufs rw,userquota 1 2
```

Для включения групповых квот используйте `groupquota`. Чтобы включить квоты как для пользователей, так и для групп, разделите параметры запятой:

```
/dev/da1s2g    /home    ufs rw,userquota,groupquota 1 2
```

По умолчанию файлы квот хранятся в корневом каталоге файловой системы как quota.user и quota.group. Дополнительную информацию см. в `fstab(5)`. Не рекомендуется указывать альтернативное расположение для файлов квот.

После завершения **Конфигурация** перезагрузите систему, и /etc/rc автоматически выполнит соответствующие команды для создания начальных файлов квот для всех квот, включенных в /etc/fstab.

В штатном режиме работы нет необходимости вручную запускать команды `quotacheck(8)`, `quotaon(8)` или `quotaoff(8)`. Однако следует ознакомиться с соответствующими страницами руководства, чтобы понимать принципы их работы.

### Установка ограничений квоты

Чтобы убедиться, что квоты включены, выполните:

```shell
# quota -v
```
