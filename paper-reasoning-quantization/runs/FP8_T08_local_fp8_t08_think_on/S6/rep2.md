## Moderator

Модератор — это детерминированная контрольная плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями от валидированных выходов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | аналитическая-задача обзоры |
| top_p | 0.9 | аналитическая-задача обзоры |
| frequency_penalty | 0.0 | нейтрально (задано явно, никогда не выводится) |

Белый список по умолчанию управляется централизованно в файле `defaults/policy.yaml`. Для расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит необходимые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Нет несанкционированных инструкций, добавленных за пределами определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел "Роль_agent_config", в котором перечислены точные параметры, использованные для каждой активной роли, и которые можно отследить до конфигурации сценария → резолюции фабрики → фактической инстанции агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (границы задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентированием/внедрением контекста — поведенческое замещение запрещено.
