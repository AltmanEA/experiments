## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `id_объекта_обсуждения`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения по Фазе и Консенсусу являются детерминированными функциями валидированных выводов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов из валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указывается вызывающей стороной, либо берется из задокументированного безопасного замечания, отображаемого в манифесте сессии. Никаких магических значений по умолчанию. Все примененные замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | обзоры аналитических задач |
| top_p | 0.9 | обзоры аналитических задач |
| frequency_penalty | 0.0 | нейтральная (задаётся явно, никогда не выводится) |

Стандартный белый список управляется централизованно в `defaults/policy.yaml`. Для расширения требуется PR с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед добавлением в очередь, проверьте:

- Идентификатор Роль совпадает с известной Ролью из `protocol-core/index.md`
- Шаблон запроса содержит обязательные разделы (перспектива, обязанности, напоминание о структуре вывода)
- Никаких несанкционированных инструкций не добавлено за пределами определения Роль и контекста Сценарий

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, содержащий точные параметры, использованные для каждой активной роли, которые прослеживаются до конфигурации сценария → резолюции фабрики → фактического инстанцирования агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для Сценария (область Задачи, название Сценария, результаты предварительной Фазы), но НЕ изменяет базовый шаблон запроса Роли. Настройка запроса ограничивается только акцентом/вставкой контекста — поведенческая подмена запрещена.
