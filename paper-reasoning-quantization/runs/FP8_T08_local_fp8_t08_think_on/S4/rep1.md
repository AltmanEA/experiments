### ConsensusVerdict

| Поле | Тип | Обязательно | Правило |
|-------|------|----------|------|
| `session_id` | string | да | |
| `phase_id` | integer | да | `4` |
| `outcome` | enum | да | `консенсус`, `условно`, `без-консенсуса`, `блокировка-эскалации` |
| `role_statuses` | RoleStatus[] | да | По одной для каждой активной роли; без пропусков |
| `blocking_subjects` | string[] | да | Субъекты со статусом блокировки |
| `disagreement_subjects` | string[] | да | Субъекты с расхождением: имеют `support` и `oppose` в финальном раунде |
| `escalation_reason` | enum \| null | условно | Требуется, когда `outcome = blocked-эскалация` |
| `computed_at` | timestamp | да | |

### ValidationResult

`` `{check: Объект обсуждения-reference|формат-обоснования|извлечение-статуса, Объект обсуждения_id: string|null, valid: boolean, code: VAL.*|PROT.*, message: string (redacted), Уровень серьёзности: Уровень серьёзности|null}` — `subject_id` и `Уровень серьёзности` опциональны; остальное обязательно. ``
