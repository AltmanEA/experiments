## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет результаты по `subject_id`, оценивает консенсус через слой 0 и направляет эскалацию. Он не выполняет интерпретацию произвольного текста, не обладает полномочиями для принятия решений и не содержит вызовов LLM. Решения, касающиеся фазы и консенсуса, являются детерминированными функциями проверенных выводов ролей; ни одна модель не участвует в потоке управления или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика создаёт экземпляры **ролевых агентов** на основе валидированного **конфига сценария**.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применяемые замечания по умолчанию отображаются в записи сессии под ключами `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область применения |
|-----------|--------------|---------------------|
| temperature | 0.1 | Задача: анализ обзоров |
| top_p | 0.9 | Задача: анализ обзоров |
| frequency_penalty | 0.0 | нейтральный (явно заданный, никогда не выводится) |

Список разрешённых по умолчанию поддерживается централизованно в `defaults/policy.yaml`. Для его расширения требуется подготовка pull request с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но перед постановкой в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит необходимые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Никакие несанкционированные инструкции не добавлены за пределы определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает секцию `"role_agent_config"`, в которой указаны точные параметры, использованные для каждой активной роли, с возможностью отследить путь от конфигурации сценария → резолюции фабрики → фактической инстанции агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты до фазы), но НЕ изменяет базовый шаблон подсказки роли. Кастомизация подсказки ограничена только акцентированием внимания/внедрением контекста — замена поведения запрещена.
