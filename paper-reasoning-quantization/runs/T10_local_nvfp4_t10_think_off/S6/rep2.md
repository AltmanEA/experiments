## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет результаты по `subject_id`, оценивает консенсус через Уровень 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию произвольного текста, не обладает полномочиями по принятию решений и не содержит вызовов языковой модели. Решения, касающиеся фазы и консенсуса, являются детерминированными функциями от проверенных выходных данных ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика создающая экземпляры ролевого агента на основе проверенной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все примененные замечания по умолчанию отображаются в записи сессии под ключом `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | По умолчанию | Область |
|-----------|---------|-------|
| temperature | 0.1 | analytical-Задача Задача reviews |
| top_p | 0.9 | analytical-Задача Задача reviews |
| frequency_penalty | 0.0 | neutral (explicitly set, never inferred) |

Список разрешённых значений по умолчанию централизованно управляется в файле `defaults/policy.yaml`. Для его расширения требуется внести изменения в виде pull request с обоснованием. Проверка и обновление осуществляются раз в квартал.

### Contract validation hook

После создания, но перед постановкой в очередь, выполните проверку:

- Идентификатор роли совпадает с известной ролью из `protocol-core/index.md`
- Шаблон запроса содержит требуемые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Незапланированные инструкции не добавляются за пределами определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, перечисляющий точные параметры, используемые для каждой активной роли, с возможностью отслеживания вплоть до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты до фазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентированием внимания/внедрением контекста — подмена поведения запрещена.
