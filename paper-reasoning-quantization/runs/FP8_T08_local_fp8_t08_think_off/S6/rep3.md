## Moderator

Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Слой 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями по принятию решений и не содержит вызовов LLM. Решения, касающиеся фазы и консенсуса, являются детерминированными функциями проверенных выводов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

## RoleAgentFactory

Централизованная фабрика, создающая экземпляры ролевых агентов на основе валидированной конфигурации сценария.

### Zero silent defaults policy (ADR-002)

Каждый параметр либо указан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Никаких магических значений по умолчанию. Все применённые замечания по умолчанию отображаются в записи сессии под ключом `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

| Параметр | Значение по умолчанию | Область применения |
|-----------|-----------------------|---------------------|
| temperature | 0.1 | Задачи аналитического обзора |
| top_p | 0.9 | Задачи аналитического обзора |
| frequency_penalty | 0.0 | нейтральная (явно задано, никогда не выводится) |

Список белых по умолчанию управляется централизованно в файле `defaults/policy.yaml`. Внесение изменений требует создания pull-запроса с обоснованием. Пересматривается ежеквартально.

### Contract validation hook

После создания, но до добавления в очередь, проверьте:

- Идентификатор роли соответствует известной роли из `protocol-core/index.md`
- Шаблон запроса содержит необходимые разделы (перспектива, обязанности, напоминание о структуре вывода)
- Никакие несанкционированные инструкции не добавлены за пределы определения роли и контекста сценария

### Session manifest traceability

Каждая запись сессии включает раздел `"role_agent_config"`, в котором перечисляются точные параметры, использованные для каждой активной роли, с возможностью отслеживания до конфигурации сценария → резолюции фабрики → фактической инстанции агента.

### No prompt modification rule

Фабрика внедряет контекст, специфичный для сценария (объем задачи, название сценария, результаты до фазы), но НЕ изменяет базовый шаблон запроса для данной роли. Настройка запроса ограничивается только акцентом/внедрением контекста — подмена поведения запрещена.
