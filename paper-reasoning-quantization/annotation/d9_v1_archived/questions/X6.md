 22|

## Вопрос 1 — кандидаты. Ответ: одна строка из цифр, по одной на кандидата
(порядок A1, A2, …): `0` — не дефект; `1`/`2`/`3` — дефект, minor/major/critical.
Например, для 4 кандидатов: `0203` (A2 — major, A4 — critical, остальные — не дефекты).

- **A1** [формат] EN:31 — цитата: `"role_agent_config"` — токен `"role_agent_config"` из EN не найден в RU дословно ⚠ пограничный
- **A2** [формат] RU:31 — цитата: `"Роль_agent_config"` — Technical identifier (JSON key) was partially translated; must be byte-identical to source. ⚠ пограничный
- **A3** [формат] RU:31 — цитата: `Роль_agent_config` — Code token altered; the original token "role_agent_config" was changed to "Роль_agent_config", breaking byte‑identical requirement. ⚠ пограничный
- **A4** [термин] RU:5 — цитата: `Role Agent` — глоссарий: требуется RU-эквивалент «Ролевой агент» — не найден ⚠ пограничный
- **A5** [термин] RU:3 — цитата: `статусы ролей` — Incorrect term used for "Role Status"; should be "Статус роли" (singular) instead of "статусы ролей". ⚠ пограничный
- **A6** [добавление] RU:3 — цитата: `вывод` — RU-слово «вывод» — эквивалент термина, которого нет в EN этого прогона ⚠ пограничный
- **A7** [добавление] RU:11 — цитата: `замечания` — RU-слово «замечания» — эквивалент термина, которого нет в EN этого прогона ⚠ пограничный
- **A8** [формулировка] RU:3 — цитата: `Решения по Фаза` — Incorrect grammatical case for the glossary term 'Фаза' (should be 'Фазам' or 'Фазе'). ⚠ пограничный
- **A9** [формулировка] RU:15 — цитата: `аналитическая-задача обзоры` — Literal, ungrammatical translation of 'analytical-task reviews'. ⚠ пограничный
- **A10** [смысл] RU:11 — цитата: `безопасного замечания` — The term 'value' (and 'defaults' in the second instance) was mistranslated as 'замечание' (remark/note) instead of 'значение'. ⚠ пограничный
- **A11** [формулировка] RU:3 — цитата: `по Фаза и Консенсус` — Grammatical error in phrase "по Фаза и Консенсус"; correct case is needed (e.g., "по Фазе и Консенсусу"). ⚠ пограничный
- **A12** [формулировка] RU:31 — цитата: `фактической инстанциирования` — Gender mismatch: 'инстанциирование' is neuter, but the adjective 'фактической' is feminine. ⚠ пограничный
