## Вопрос 1 — кандидаты. Ответ: одна строка из цифр, по одной на кандидата
(порядок A1, A2, …): `0` — не дефект; `1`/`2`/`3` — дефект, minor/major/critical.
Например, для 4 кандидатов: `0203` (A2 — major, A4 — critical, остальные — не дефекты).

- **A1** [термин] EN:3 — цитата: `Phase` — глоссарий: требуется RU-эквивалент «Фаза» — не найден ⚠ пограничный
- **A2** [термин] EN:31 — цитата: `Resolution` — глоссарий: требуется RU-эквивалент «Резолюция» — не найден ⚠ пограничный
- **A3** [термин] RU:5 — цитата: `Role` — глоссарий: требуется RU-эквивалент «Роль» — не найден ⚠ пограничный
- **A4** [термин] RU:5 — цитата: `Role Agent` — глоссарий: требуется RU-эквивалент «Ролевой агент» — не найден ⚠ пограничный
- **A5** [термин] RU:31 — цитата: `запись сеанса` — The required glossary term "Session" (Сессия) is not used; the translation uses "сеанса" instead of the required term. ⚠ пограничный
- **A6** [термин] RU:3 — цитата: `результаты` — The required glossary term "Finding" (Вывод) is not used; the translation uses "результаты" instead of the required term. ⚠ пограничный
- **A7** [термин] RU:31 — цитата: `сеанса` — The term 'session' is translated as 'сеанса', but the glossary requires 'Сессия'. ⚠ пограничный
- **A8** [добавление] RU:17 — цитата: `вывод` — RU-слово «вывод» — эквивалент термина, которого нет в EN этого прогона ⚠ пограничный
