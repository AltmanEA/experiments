## Вопрос 1 — кандидаты. Ответ: одна строка из цифр, по одной на кандидата
(порядок A1, A2, …): `0` — не дефект; `1`/`2`/`3` — дефект, minor/major/critical.
Например, для 4 кандидатов: `0203` (A2 — major, A4 — critical, остальные — не дефекты).

- **A1** [формулировка] RU:15 — цитата: `Отсутствие Роль Core` — Incorrect case for the term 'Роль'; it should be in the genitive case ('роли') following the word 'Отсутствие'. ⚠ пограничный

## Вопрос 2 — другие фактические искажения (числа, подмена терминов,
потеря/добавление смысла), которых нет в списке кандидатов?
Ответ — одно число: `0` — нет; `1`/`2`/`3` — нашли искажение
minor/major/critical. Несколько — через запятую (например `3,2`).
