# X19#4 (вопрос 4 из 5 по прогону X19)

Судья усомнился в этом фрагменте. EN: «- Missing Core role or invalid-format status also routes to `blocked-escalation` with the appropriate reason, checked independently of this table.»  
RU: «- Отсутствие Роль Core или статус с неверным форматом также приводит к `blocked-escalation` с соответствующей причиной, проверяемой независимо от этой таблицы.»  
Утверждается: Incorrect case for the term 'Роль'; it should be in the genitive case ('роли') following the word 'Отсутствие'.  
Это фактическое искажение перевода?

0 = не искажение; 1 = minor; 2 = major; 3 = critical.
