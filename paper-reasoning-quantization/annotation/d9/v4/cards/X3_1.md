# X3#1 — абзац 1

**EN:**

> ## Moderator
> The Moderator is the deterministic control plane inside `orchestrator/`. It aggregates role statuses, joins findings by `subject_id`, evaluates consensus through Layer 0, and routes escalation. It performs no free-text interpretation, holds no decision power, and contains no LLM call. Phase and consensus decisions are deterministic functions of validated role outputs; no model participates in control flow or safety verification.

**RU:**

> ## Moderator
> Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через Layer 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию произвольного текста, не наделён полномочиями по принятию решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями валидированных выходов ролей; ни одна модель не участвует в управлении потоком или проверке безопасности.

**Вопрос.** Числа/идентификаторы должны совпадать. EN `0` → RU `0`. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
