# X15#1 — абзац 1

**EN:**

> ## Deterministic Control Plane
> Moderator control flow and every phase, consensus, and escalation decision are deterministic functions of validated role outputs. No LLM participates in control flow or safety verification. The Moderator may read free text only for display; it never interprets it to make a decision. Scenario loading falls back to `default-council-session` (see `scenario/default-council-session.yaml`) when no explicit `scenario_id` is provided in the session manifest.

**RU:**

> ## Deterministic Control Plane
> Поток управления модератора и каждый этап, консенсус и решение об эскалации являются детерминированными функциями проверенных выходов ролей. Ни одна LLM не участвует в потоке управления или проверке безопасности. Модератор может читать свободный текст только для отображения; он никогда не интерпретирует его для принятия решений. Загрузка сценария по умолчанию использует `default-council-session` (см. `scenario/default-council-session.yaml`), если в манифесте сессии не указан явный `scenario_id`.

**Вопрос.** По глоссарию термин «Session» передаётся как «Сессия». Здесь EN «Session» → RU содержит «Сессия». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
