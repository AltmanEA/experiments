# X5#1 — абзац 1

**EN:**

> ### Zero silent defaults policy (ADR-002)
> Every parameter either specified by caller OR taken from a documented safe value visible in session manifest. No magic defaults. All applied defaults appear in session record under `"configuration_source": "scenario_defaults"` or `"configuration_source": "operator_explicit"`.

**RU:**

> ### Zero silent defaults policy (ADR-002)
> Каждый параметр либо задан вызывающей стороной, либо взят из задокументированного безопасного замечания, видимого в манифесте сессии. Магических значений по умолчанию нет. Все применённые замечания по умолчанию отображаются в записи сессии в поле `"configuration_source": "scenario_defaults"` или `"configuration_source": "operator_explicit"`.

**Вопрос.** Числа/идентификаторы должны совпадать. EN `002` → RU `002`. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
