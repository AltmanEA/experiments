# X15#5 — абзац 5

**EN:**

> Only `orchestrator/` advances a phase. The operator never edits phase state directly; resolution arrives through the operator surface. The `SUBJ-007` quick-review upgrade hook is reserved but not implemented at MVP.

**RU:**

> Только `orchestrator/` продвигает фазу. Оператор никогда не редактирует состояние фазы напрямую; разрешение приходит через интерфейс оператора. Хук быстрого обновления `SUBJ-007` зарезервирован, но не реализован на этапе MVP.

**Вопрос.** По глоссарию термин «Resolution» требуется передавать как «Резолюция». Здесь EN «Resolution» → в RU слова «Резолюция» нет. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
