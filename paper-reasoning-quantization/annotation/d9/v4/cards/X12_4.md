# X12#4 — абзац 4

**EN:**

> ### Session manifest traceability
> Each session record includes `"role_agent_config"` section listing exact parameters used for each active role, traceable back to scenario config → factory resolution → actual agent instantiation.

**RU:**

> ### Session manifest traceability
> Каждая запись сессии включает раздел `"role_agent_config"`, в котором перечислены точные параметры, использованные для каждой активной роли, с возможностью проследить их до конфигурации сценария → резолюции фабрики → фактической инстанции агента.

**Вопрос.** По глоссарию термин «Scenario» передаётся как «Сценарий». Здесь EN «Scenario» → RU содержит «Сценарий». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
