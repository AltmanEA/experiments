# X22#3 — абзац 3

**EN:**

> - **Target scope:** all manifest documents relevant to the current session (identified by `target_id` from the active scenario).
> - **Enforcement point:** invoked at every phase boundary transition (`2 → 3`, `3 → 4`, `4 → 5`) before committing the new phase state in Layer 1.
> - **Gated transitions:** `2 → 3` (discussion start), `3 → 4` (consensus check), `4 → 5` (resolution). Transition is permitted only when the verdict is `pass`.
> - **Verdict handoff to Layer 1:** the surface writes the verdict result (pass/fail/reason) into the manifest field `pre_check_override` on override or emits a `precheck.failed` event; the runtime reads this field/event at the next boundary evaluation and either proceeds or blocks accordingly.

**RU:**

> - **Целевой охват:** все манифест-документы, относящиеся к текущей сессии (определяемые `target_id` из активной сценарии).
> - **Точка принудительного выполнения:** вызывается на каждом переходе между фазами (`2 → 3`, `3 → 4`, `4 → 5`) перед фиксацией нового состояния фазы в Слое 1.
> - **Ограниченные переходы:** `2 → 3` (начало обсуждения), `3 → 4` (проверка консенсуса), `4 → 5` (резолюция). Переход разрешен только при вердикте `pass`.
> - **Передача вердикта в Слой 1:** поверхность записывает результат вердикта (pass/fail/причина) в поле манифеста `pre_check_override` при переопределении или генерирует событие `precheck.failed`; среда выполнения считывает это поле/событие на следующей оценке границы и либо продолжает выполнение, либо блокирует его.

**Вопрос.** Судья усомнился в фрагменте ниже. Это фактическое искажение перевода?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
