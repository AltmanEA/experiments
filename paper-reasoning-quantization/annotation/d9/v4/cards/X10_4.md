# X10#4 — абзац 4

**EN:**

> - **Target scope:** all manifest documents relevant to the current session (identified by `target_id` from the active scenario).
> - **Enforcement point:** invoked at every phase boundary transition (`2 → 3`, `3 → 4`, `4 → 5`) before committing the new phase state in Layer 1.
> - **Gated transitions:** `2 → 3` (discussion start), `3 → 4` (consensus check), `4 → 5` (resolution). Transition is permitted only when the verdict is `pass`.
> - **Verdict handoff to Layer 1:** the surface writes the verdict result (pass/fail/reason) into the manifest field `pre_check_override` on override or emits a `precheck.failed` event; the runtime reads this field/event at the next boundary evaluation and either proceeds or blocks accordingly.

**RU:**

> - **Область действия:** все манифестные документы, относящиеся к текущей сессии (определяемые по `target_id` из активного сценария).
> - **Точка принуждения:** вызывается при каждом переходе между фазами (`2 → 3`, `3 → 4`, `4 → 5`) перед фиксацией нового состояния фазы в Слое 1.
> - **Переходы с контролем:** `2 → 3` (начало обсуждения), `3 → 4` (проверка консенсуса), `4 → 5` (принятие резолюции). Переход разрешён только при вердикте `pass`.
> - **Передача вердикта в Слой 1:** поверхность записывает результат вердикта (pass/fail/причина) в поле манифеста `pre_check_override` при переопределении или генерирует событие `precheck.failed`; среда выполнения считывает это поле/событие на следующей границе оценки и либо продолжает выполнение, либо блокирует его соответственно.

**Вопрос.** По глоссарию термин «Session» передаётся как «Сессия». Здесь EN «Session» → RU содержит «Сессия». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
