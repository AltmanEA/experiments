# X5#5 — абзац 5

**EN:**

> ### No prompt modification rule
> Factory injects scenario-specific context (task scope, scenario name, pre-phase results) but does NOT modify the role's base prompt template. Prompt customization scoped to emphasis/context injection only — behavioral substitution prohibited.

**RU:**

> ### No prompt modification rule
> Фабрика внедряет контекст, специфичный для сценария (объем задачи, название сценария, результаты пред-фазы), но НЕ изменяет базовый шаблон промта роли. Настройка промта ограничена только акцентированием внимания/внедрением контекста — подмена поведения запрещена.

**Вопрос.** По глоссарию термин «Role» требуется передавать как «Роль». Здесь EN «Role» → в RU слова «Роль» нет. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
