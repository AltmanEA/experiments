> | `raised_by_role` | string | yes | |
> | `reason` | enum | yes | `escalation_reason` |

**Вопрос.** Токен кода должен остаться без изменений (байт в байт). EN `escalation_id` → RU `escalation_id`. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
