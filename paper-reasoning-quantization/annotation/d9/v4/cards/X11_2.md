# X11#2 — абзац 2

**EN:**

> ### Scope and Enforcement Point
> The `pre_check` gate is an integrity check on documentation artifacts before protocol state transitions are committed. It runs in Layer 2 (operator surface) as a synchronous call to Documenter's `audit(pre_check=true)` and returns a verdict to the caller within the same invocation.

**RU:**

> ### Scope and Enforcement Point
> Шлюз `pre_check` представляет собой проверку целостности артефактов документации перед фиксацией переходов состояния протокола. Он выполняется на уровне 2 (поверхность оператора) в виде синхронного вызова `audit(pre_check=true)` в Документаторе и возвращает вердикт вызывающей стороне в рамках того же вызова.

**Вопрос.** По глоссарию термин «Documenter» передаётся как «Документатор». Здесь EN «Documenter» → RU содержит «Документатор». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
