# X5#3 — абзац 3

**EN:**

> ## Moderator
> The Moderator is the deterministic control plane inside `orchestrator/`. It aggregates role statuses, joins findings by `subject_id`, evaluates consensus through Layer 0, and routes escalation. It performs no free-text interpretation, holds no decision power, and contains no LLM call. Phase and consensus decisions are deterministic functions of validated role outputs; no model participates in control flow or safety verification.

**RU:**

> ## Moderator
> Модератор — это детерминированная управляющая плоскость внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет выводы по `subject_id`, оценивает консенсус через слой 0 и маршрутизирует эскалацию. Он не выполняет интерпретацию свободного текста, не обладает полномочиями принятия решений и не содержит вызовов LLM. Решения по фазе и консенсусу являются детерминированными функциями проверенных выводов ролей; ни одна модель не участвует в управляющем потоке или проверке безопасности.

**Вопрос.** Токен кода должен остаться без изменений (байт в байт). EN `subject_id` → RU `subject_id`. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
