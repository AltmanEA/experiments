# X24#3 — абзац 3

**EN:**

> ## Moderator
> The Moderator is the deterministic control plane inside `orchestrator/`. It aggregates role statuses, joins findings by `subject_id`, evaluates consensus through Layer 0, and routes escalation. It performs no free-text interpretation, holds no decision power, and contains no LLM call. Phase and consensus decisions are deterministic functions of validated role outputs; no model participates in control flow or safety verification.

**RU:**

> ## Moderator
> Модератор — это детерминированная управляющая плоскость, расположенная внутри `orchestrator/`. Он агрегирует статусы ролей, объединяет результаты по `subject_id`, оценивает консенсус через слой 0 и маршрутизирует эскалацию. Модератор не выполняет интерпретацию произвольного текста, не обладает полномочиями для принятия решений и не содержит вызовов больших языковых моделей (LLM). Решения относительно фазы и консенсуса являются детерминированными функциями проверенных выходов ролей; никакая модель не участвует в управлении потоком выполнения или проверке безопасности.

**Вопрос.** По глоссарию термин «Role» требуется передавать как «Роль». Здесь EN «Role» → в RU слова «Роль» нет. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
