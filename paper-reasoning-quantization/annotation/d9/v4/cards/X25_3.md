# X25#3 — абзац 3

**EN:**

> ### No prompt modification rule
> Factory injects scenario-specific context (task scope, scenario name, pre-phase results) but does NOT modify the role's base prompt template. Prompt customization scoped to emphasis/context injection only — behavioral substitution prohibited.

**RU:**

> ### No prompt modification rule
> Фабрика внедряет контекст, специфичный для сценария (область задачи, название сценария, результаты предфазы), но НЕ изменяет базовый шаблон запроса роли. Настройка запроса ограничена только акцентом/внедрением контекста — поведенческая подмена запрещена.

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
