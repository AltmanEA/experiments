# X29#3 — абзац 3

**EN:**

> ### ValidationResult
> `{check: subject-reference|justification-format|status-extraction, subject_id: string|null, valid: boolean, code: VAL.*|PROT.*, message: string (redacted), severity: severity|null}` — `subject_id` and `severity` optional; the rest required.

**RU:**

> ### ValidationResult
> `{check: subject-reference|justification-format|status-extraction, subject_id: string|null, valid: boolean, code: VAL.*|PROT.*, message: string (redacted), severity: severity|null}` — `subject_id` и `Уровень серьёзности` опциональны; остальное обязательно.

**Вопрос.** Токен кода должен остаться без изменений (байт в байт). EN `severity` → в RU дословно нет, ближайшее `subject_id`. Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
