# X3#4 — абзац 4

**EN:**

> ### Session manifest traceability
> Each session record includes `"role_agent_config"` section listing exact parameters used for each active role, traceable back to scenario config → factory resolution → actual agent instantiation.

**RU:**

> ### Session manifest traceability
> Каждая запись сессии содержит раздел `"role_agent_config"`, в котором указаны точные параметры, использованные для каждой активной роли, и которые можно отследить до конфигурации сценария → резолюции фабрики → фактической инициализации агента.

**Вопрос.** По глоссарию термин «Resolution» передаётся как «Резолюция». Здесь EN «Resolution» → RU содержит «Резолюция». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
