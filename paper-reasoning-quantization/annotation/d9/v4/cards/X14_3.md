# X14#3 — абзац 3

**EN:**

> ## Out of Scope
> - Software code generation or code analysis
> - Code execution or runtime monitoring
> - General-purpose chat or conversational AI
> - Project management beyond the boundary of a single task

**RU:**

> ## Out of Scope
> - Генерация программного кода или анализ кода
> - Выполнение кода или мониторинг во время выполнения
> - Чат общего назначения или диалоговый ИИ
> - Управление проектами за пределами границ одной задачи

**Вопрос.** По глоссарию термин «Task» передаётся как «Задача». Здесь EN «Task» → RU содержит «Задача». Это искажение?

Ответ одной цифрой: 0 = не искажение; 1 = minor; 2 = major; 3 = critical.
