время 364 c. Локальные thinking-условия (C4/C6) такого не дают — там trace отделён.

**Решение (2026-11-12):** trace вырезается пост-обработкой — `metrics/strip_trace.py`, см. NOTES.md
P-001b. Фильтр детерминированный, на шести «чистых» условиях удаляет 0 строк; на C2 удалено 6308
строк (288/прогон) и развёрнуто 345 «полезных нагрузок» строк `Final:`/`Translation:` (иначе
терялся сам перевод табличных строк). Для сравнений используется `C2_clean`; raw-цифры остаются как характеристика
дефекта «как есть».

## Инфраструктура

- `cloud_paced.sh` — серийный облачный раннер: gate (`can_request`, cooldown, RPM ≥20,
  session/week reserve 15 %), адаптивный пейсинг ≤40 RPM, `MAX_RETRIES=1`, DEGRADED только по
  `[retry]/429`.
- `cloud_worker.sh` — параллельный воркер: непересекающийся набор фикстур, lock на фикстуру,
  тот же gate, пометка `concurrency=3 worker=wN` в `runs/runlog.txt`.
- `run_progress.sh` — локальный раннер (preflight сверяет model id, прогресс в `runs/progress_*.txt`).
- `metrics/defects.py` (D1–D7 + D5_nc/D7_nc без инлайн-кода), `metrics/aggregate.py` (+ `results/`;
  для `*_clean` wall-time наследуется из базового условия).
- `metrics/strip_trace.py` — вырезание leakage (правила R1–R9 + дедуп), `--dir/--out-dir/--dedup/--en-dir`.
- `metrics/make_gloss_pairs.py` — EN→RU пары из `docs/en/glossary/index.md`: `corpus/gloss_pairs.txt`
  (54 пары) и `corpus/gloss_pairs/S*.txt` (пары, встречающиеся в фикстуре: 6…15).
- `metrics/judge_batch.py` — батч-судья: MQM absolute / pairwise, resume-safe, gate `/v1/limits`,
  пейсинг (`--rpm`), `--timeout`, режим `--repair` (только ячейки `_status=fail`);
  результаты `judge/<mode>/<cond>/<fix>/rep<k>.<judge>.json`, свод `results/judge_<mode>.csv`.
- `metrics/judge_report.py` — MQM-таблицы с bootstrap-CI, матрица по фикстурам, согласие судей.
- `metrics/judge_effects.py` — парные контрасты условий (`results/judge_effects.md/.csv`).
- `metrics/article_tables.py` — сводные таблицы статьи (`results/article_tables.md`).
- Прогресс: `runs/progress_<условие>.txt`, `runs/progress_C2_cloud_bf16_think_on__w1|w2.txt`,
  общий `runs/progress_cloud.out`; сырьё — `runs/<условие>/<фикстура>/rep<k>.md|.log`.
