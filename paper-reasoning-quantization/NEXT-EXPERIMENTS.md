## 2. Этап 0 — бесплатно, без GPU и облака

**Общее.** GPU (NVFP4/FP8) не занимает вовсе; облачная квота почти не тратится (10 оценок
в P-003c), поэтому Этап 0 делается в любой день и не конкурирует с P-002a за квоту.
Трудозатраты ≈ 5–7 чел-час; P-003a/b/c независимы и параллелятся (стена-в-стену ≈ 2–2.5 ч),
P-003d — последним, когда a–c дали финальные числа.

**Окружение.** Системный `python3` — venv vLLM-сервера (`/home/ea/.venv`): там есть `numpy`,
нет `pip`/`scipy`/`matplotlib`/`sacrebleu`, и менять его нельзя (риск сломать сервер).
Решение: отдельный venv проекта через `uv`:

```bash
cd paper-reasoning-quantization
uv venv .venv-analysis
uv pip install --python .venv-analysis/bin/python scipy matplotlib sacrebleu
# скрипты Этапа 0 запускать этим интерпретатором:
.venv-analysis/bin/python metrics/judge_effects.py
```

### P-003b: статпроверки и графики (§6.3)

- Уилкоксон signed-rank по фикстурам как блокам для всех контрастов; поправка Holm
  по семействам (thinking-семейство, квантовое, температурное); α = 0.05.
- Порог «эффект vs шум»: расхождение значимо, если превышает 95-й перцентиль
  внутриконфигурного разброса повторов; шумовой пол — из T00 (8.4 по смешанной шкале,
  отдельно посчитать чистый sd повторов по дефектным метрикам).
- Требуется `scipy` и `matplotlib` — из `.venv-analysis` (§2). Перестановочный тест при
  желании реализуется на numpy (~30 строк), но scipy дешевле по времени.
- Графики (matplotlib, в `results/figs/`): (1) off-кривая MQM vs T с CI и точкой-выбросом
  0.2; (2) thinking-дефицит по T; (3) D3 code-порча по T (off/on); (4) шум по T;
  (5) матрица фикстура × условие для D3 (концентрация дефекта на S4/S5).
- **Выполнено 2026-11-15.** `metrics/stats_tests.py` → `results/stats_tests.md/.csv`:
  Wilcoxon signed-rank (парные дельты по 21 единице фикстура×повтор, судьи усреднены —
  та же пайровка, что в judge_effects.py) + Holm по семействам (thinking/quantization/
  temperature/other + по одному на дефектную метрику), α=0.05; отдельно MQM-уровень и
  дефектный (D3/D4/D5nc/D6/D7nc). Порог E-008: pooled 95-й перцентиль |Δповтор| внутри
  обоих условий контраста; «effect=YES» = p_holm<α И |Δ|>порога. Итоги: thinking-семейство —
  значимы T=0.0/0.2/0.4/0.6 (p_holm ≤0.018), 0.8–1.0 нет; H3 целиком незначима (p_holm ≥0.71);
  из температурных после Holm выживают только off-тренды 0.2 (0.040) и 1.0 (0.024) — on-тренды

  Шумовой пол T=0: MQM p95 |Δповтор| = 17.5 (off) / 35.0 (on); чистые sd повторов дефектных
  метрик при greedy = 0.00 (весь MQM-шум пола — сервер + судья). D5nc «no glossary» +1.19
  значим (p_holm=0.011), но ниже порога шума.
  `metrics/make_figs.py` → `results/figs/fig1…fig5.png` (все 5, цифры сверены с таблицей 5
